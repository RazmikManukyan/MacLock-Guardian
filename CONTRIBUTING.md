# Contributing

Thank you for helping improve MacLock Guardian.

- Be considerate of user privacy; camera and location access must require informed opt-in and native macOS permission.
- Never submit real tokens, chat IDs, coordinates or security photos.
- Keep all monitoring opt-in and easy to disable; do not bypass macOS privacy controls.
- Describe your macOS version and hardware architecture when reporting bugs.
- Include test procedures and exact, **redacted** failure messages.
- Avoid claiming that an untested security-sensitive feature is reliable.
